# Contributing

1. Create a focused branch from `main`.
2. Keep the Rust API and TypeScript types in sync.
3. Add or update tests for behavior changes.
4. Run the verification commands from the README.
5. Keep UI strings in `web/src/i18n.ts`; do not add user-facing text directly to components when a translation key is appropriate.

Bug reports should include the container networking mode, host operating system, LocalSend peer version, and relevant logs with private filenames or addresses removed.
